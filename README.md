# Slate - Academic Operating System (Fall 2026)

> **"Built by Saim & run by Slate"**  
> A fast, zero-friction academic companion for BSCS Green (Fall 2026).

- **Live URL:** [https://try-slate.web.app](https://try-slate.web.app)  
- **Hosting:** Firebase Hosting (Google Global CDN)  
- **Stack:** React 19, TypeScript, Tailwind CSS v4, Vite, Mozilla PDF.js

---

## Features

- **Instant 0ms Navigation:** JSON-driven recursive tree architecture (`semester_1.json` and `timetable.json`). Course selection, weekly folder diving, and schedule lookups execute in client memory with zero server roundtrips.
- **In-Browser Document Previewer:** Preview PDFs, PowerPoint slides (`.pptx`), Word documents (`.docx`), Markdown notes, and video lectures directly in the browser with zero external download manager popups.
- **Persistent On-Disk Offline Caching:**
  - Full-file download on initial access, saved persistently to device disk via Cache API (`slate-academic-vault-v1`) with IndexedDB fallback (`academicCache.ts`).
  - Subsequent opens load instantaneously in 0ms with complete offline availability across mobile and desktop.
  - Zero module-level RAM hoarding: documents are handled via ephemeral Blob URLs revoked immediately upon closing the modal.
- **Animated Slate Mascot Loading Card:**
  - Displays centered Slate mascot animation with live percentage tracking.
  - Informs students that initial downloads are being saved to disk for offline access.
- **2D Grid Spatial Keyboard Navigation:**
  - `Left` / `Right` / `Up` / `Down` : Move between columns and rows with balanced eye-level viewport centering.
  - `Enter` : Open selected course, folder, or file preview.
  - `Backspace` / `Esc` : Step back up a directory level or close preview.
  - `1` through `5` : Jump to Monday through Friday in the timetable.
  - `?` : Open keyboard shortcut cheat sheet.
- **Neo-Brutalist Whiteboard Design:**
  - Hand-drawn subject logos with interactive physics and hover animations.
  - Custom interactive vector Slate mascot featuring "The Hello Wave" state in the footer.
  - **Zero-Emoji Law:** Strictly clean vector SVGs, zero fake SaaS badges, pure educational utility.

## Local Development

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Run dev server with network host enabled for mobile testing
npm run dev -- --host

# Build for production
npm run build
```

---

## Deployment & CI/CD

This repository is connected to Firebase Hosting via GitHub Actions. Every push to the `main` branch automatically triggers the build and deployment pipeline to [https://try-slate.web.app](https://try-slate.web.app).

Manual deploy:
```bash
firebase deploy --only hosting --project try-slate
```
